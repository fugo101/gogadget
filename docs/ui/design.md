# UI design

## Display

- 320x170 landscape, RGB565. Default orientation: USB connector on the left (LilyGO's default). A setting rotates by 180° (USB on the right); it applies at the next boot, which on battery is every wake.
- The panel is an IPS ST7789V. Colours differ from the simulator: pure red renders orange and greys tint green off-axis. The palette below is approved once on the real panel from a photo; the simulator is the reference for layout, not for exact colour.
- No tear-effect line exists; at 10 MHz a full frame takes about 11 ms, so redraw only what changes.

## Theme

- Dark background, high-contrast foreground; one accent colour for focus and the active timer.
- Palette (provisional until approved on hardware): background `#000000`, primary text `#FFFFFF`, secondary text `#A0A0A0`, accent `#3FA9F5`, warning `#FFB000`, error `#FF4040`.

## Fonts

- Digits: DSEG7 Classic (OFL) for the large time, generated digits-only.
- Text: Be Vietnam Pro (OFL) for everything else, with the full Vietnamese precomposed range.
- Fonts are generated by the pinned script in `tools/fonts/` from the ranges listed there; generated `.c` files are never edited by hand.
- Vietnamese strings go through `lv_tr()` so every user-visible string has one source.

## Navigation

- KEY press: Next. KEY hold: Back. BOOT press: Enter (ADR-0008).
- Lists wrap; focus is shown with the accent colour.
- Screens that accept input show small hints next to the physical buttons; the hints move with the orientation.

## Watchface v1

Layout regions (landscape, USB left):

```
+--------------------------------------------------------------+
| [battery] [wifi/sync]                       [timer] [badge]   |  status bar, ~20 px
|                                                              |
|                 HH:MM            ss                           |  time, DSEG7, ~80-96 px
|                                                              |
|          Thứ Ba, 20/10/2026        11/9 ÂL                    |  dates, Be Vietnam Pro, ~20-24 px
+--------------------------------------------------------------+
```

- The exact composition is chosen from 2-3 rendered variants (PNG) before implementation is finalised.
- Seconds update every second only while the screen is lit; the rest of the face redraws on change.
- Unknown time (never synced, or lost after an unexpected reset) shows `--:--` and the Unsynced badge.
- Always-on: the whole face shifts by 1-2 px every few minutes to limit image retention.

## Golden screenshots

- One reference PNG per screen state, named `<screen>-<state>.png` (for example `watchface-default.png`, `watchface-unsynced.png`), rendered from fixed fixtures in `ui/test/`.
- References are created locally on purpose and reviewed as image diffs; CI never creates them.
