# Write our own lunar calendar code and generate its tables from the JPL ephemeris

The Vietnamese lunar date is computed by our own integer C code from compact tables for 1900-2100, generated by a Python script from the JPL DE440s ephemeris (via Skyfield) using the Vietnamese rules: new moons and solar terms in UTC+7 from 1968 and UTC+8 before. The widely used code and tables by Hồ Ngọc Đức are licensed for personal, non-commercial use only, which is incompatible with this repository's MIT licence, so none of it is copied. Vietnamese dates differ from the Chinese calendar in some years (Tết 1985 fell on 21 January in Vietnam and 20 February in China), so Chinese tables cannot be used as-is.

## Consequences

- CI checks the generated tables against the Hong Kong Observatory tables in every year where the two calendars agree, against known Vietnam-specific years (1985, 2007, 2030, 2053, and the months near a midnight boundary), and round-trips every day from 1900 to 2100.
- Check value: 2026-10-20 is day 11 of month 9, year Bính Ngọ (day Đinh Mão, month Mậu Tuất).
